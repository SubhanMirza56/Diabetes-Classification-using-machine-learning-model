# Diabetes-Classification-using-machine-learning-model
🚀 Built My First Multi-Model Machine Learning Project on Diabetes Prediction

Today, I worked on a Diabetes Prediction System using a real-world dataset and built multiple machine learning models including:

Logistic Regression
K-Nearest Neighbors (KNN)
Decision Tree Classifier

After training and testing the models, I achieved an accuracy of 73%, which gave me a solid baseline understanding of how different algorithms perform on the same dataset.

🧠 The best part of this project was not just building models, but creating a user input system, where a user can enter medical details and the model predicts whether the person is diabetic or not.

📊 Key Learnings:

How different algorithms behave on the same dataset
Importance of preprocessing and feature selection
Building an end-to-end ML workflow (training → testing → prediction system)

🚀 Next Steps:
I’ve realized that model performance can be significantly improved through:

Hyperparameter tuning
Better feature engineering
Model optimization techniques

Once I dive deeper into these concepts, I’m confident I’ll be able to improve the accuracy beyond the current results and build a more robust system.

💡 This is just the beginning of my ML journey, and I’m excited to keep learning, improving, and building more real-world projects.
